8. KEY CONVENTIONS
═══════════════════════════════════════════════════════════════════════════════

INGESTOR CONTRACT (BaseIngestor):
  1. download()   — idempotent; ETag/content-hash check, never re-download unchanged
  2. validate()   — file integrity + record count sanity check
  3. load()       — upsert (INSERT ... ON CONFLICT DO UPDATE); never TRUNCATE + INSERT
  4. register()   — upsert row in data_source_registry

RASTER STORAGE:
  - All rasters stored as COGs in MinIO
  - MinIO key: {dataset}/{version}/{tile_id}.tif
  - PostGIS holds only tile index (raster_tiles), not raster data
  - When computing slope from DEM: buffer clip by ≥1 grid cell (~10m) before
    gdal.DEMProcessing to avoid edge artifacts
  - Files > 4 GB require BIGTIFF=YES in gdalwarp

QUERY CACHE:
  - Dataset-specific compound key strings (not flat proximity hashes):
    nasa-power:{grid_cell_id}:{param_hash}:{date_range}
    epa-aqs:{county_fips}:{year}
    usgs-eq:{grid_cell_100km}:{start_year}:{mag_threshold}
  - TTLs: NASA POWER 30d, EPA AQS 365d, USGS earthquakes 30d, FCC 90d

FEMA FLOOD DATA:
  - fema_unmapped_areas is mandatory — a site with no flood data must NEVER
    appear as Zone X; ~15-20% of US has no FEMA mapping
  - USGS aquifer code 999 ("Other rocks") is a filler polygon meaning
    "not a principal aquifer" — excluded from all aquifer lookups

FCC BROADBAND:
  - BDC API uses HTTP/2; httpx+h2 triggers server-side stream resets
  - Ingestor uses subprocess+curl workaround (see fcc_broadband.py)
  - Query uses functional index on LEFT(block_geoid, 12) — critical for
    performance (1.7s → 0.03s without the index)

REPORT OUTPUT CONSTRAINTS:
  - Present raw data values only — no derived risk ratings or suitability scores
  - FEMA NRI results must be labeled "Source: FEMA National Risk Index"
  - FCC broadband requires mandatory ISP self-reporting disclaimer
  - Every API-sourced field has a defined failure behavior (inline flag,
    never silent blank, never error)
